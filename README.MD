
# Retail Sales Analytics Dashboard

## About the Project
Retail Sales Analytics is a Python-based data analytics project that analyzes sample retail sales data and presents useful business insights through charts and an interactive dashboard.

## Objectives
- Calculate total sales revenue.
- Identify top-performing products and categories.
- Compare sales across different regions.
- Analyze monthly sales trends.
- Display sales information through an interactive dashboard.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Streamlit

## Features
- Total revenue, total orders, and total units sold.
- Sales analysis by product and category.
- Region-wise sales comparison.
- Monthly sales trend visualization.
- Interactive dashboard with a sales data table.

## Results
- Total Revenue: Rs. 288,900
- Total Orders: 15
- Total Units Sold: 158

## Project Files
- `sales.csv` — Sample sales dataset
- `analysis.py` — Sales analysis
- `charts.py` — Region-wise chart
- `category_chart.py` — Category chart
- `monthly_chart.py` — Monthly sales trend
- `insights.py` — Business insights
- `app.py` — Interactive Streamlit dashboard

## How to Run
Install the required libraries:

```bash
pip install pandas matplotlib streamlit
```

Run the dashboard:

```bash
streamlit run app.py
```
